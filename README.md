Night Market — Spot the Difference: an original canvas game where two hand-drawn scenes hang side by side in the lantern light and seven little things changed between them. Three scenes of rising difficulty — a lantern night market, a harbor at dusk, and a rooftop festival — with a ticking timer, a score, limited hints, and a satisfying chime on every find.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
